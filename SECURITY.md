# Security

Sitetend runs on your own computer and only listens on `127.0.0.1`. Every request needs the session token from the link Sitetend opens; keys are stored in `~/.sitetend/.env` only.

If you find a security problem, please do not open a public issue. Use GitHub's private vulnerability reporting for this repository (Security → Report a vulnerability), and describe how to reproduce it. You will get an answer within a week.
