# Orbit Dock — Project Overview & Changelog

- **Project ID**: `orbit-dock`
- **Category**: Systems

## Overview
Orbit Dock solves context fragmentation for solo builders. Instead of scattering bookmarks and markdown notes across folders, Orbit Dock indexes project directories and surfaces active blockers alongside recent commits.

## Verified Highlights
- Reduced project context-switching latency by 38% in a 14-participant diary study
- Zero-cloud local indexing engine with deterministic snapshot diffs
- Keyboard-first command palette with instant file preview
